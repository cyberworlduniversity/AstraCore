# AstraCoreLM — Phase 1

An independently written decoder-only Transformer in PyTorch. No external AI APIs are used anywhere.

## Audit of the existing AstraCore repository
- This Lovable project (the web app) contains **no model, tokenizer or training code** — only the frontend, which calls a remote server.
- The remote AstraCore server (Vercel) blocks all outside requests (HTTP 401, Deployment Protection), so its code could not be inspected. Nothing in it was modified.
- Everything here is therefore new and self-contained.

## Components
| Class | File | What it does |
|---|---|---|
| `AstraCoreTokenizer` | `astracorelm/tokenizer.py` | Byte-level BPE trained from scratch; lossless on any UTF-8; specials `<pad> <bos> <eos> <unk>` |
| `AstraCoreLM` / `AstraCoreConfig` | `astracorelm/model.py` | Token + learned positional embeddings, multi-head causal self-attention, GELU feed-forward, pre-LayerNorm residual blocks, tied output head, next-token loss, generation with temperature / top-p / max tokens |
| `AstraCoreTrainer` | `astracorelm/trainer.py` | Train/val/test splits, AdamW, warmup + cosine LR, grad clipping, CUDA mixed precision, measured losses and test perplexity |
| `AstraCoreCheckpointManager` | `astracorelm/checkpoint.py` | Versioned `v0001, v0002…` checkpoints with `manifest.json` (config, metrics, SHA-256 of every file); refuses to load a tampered checkpoint |
| `AstraCoreInference` | `astracorelm/inference.py` | Loads a verified checkpoint, generates text; `serve()` exposes `POST /api/chat`, `GET /api/model`, `GET /api/health` |

Device: auto-selects CUDA → Apple MPS → CPU (`--device` to override).

## Run
```bash
pip install torch pytest
python -m pytest tests
python train.py --data data/sample_corpus.txt --out checkpoints --vocab 400 --steps 300 --ctx 64 --d_model 96 --layers 2 --lr 2e-3
python -c "from astracorelm.inference import serve; serve('checkpoints')"
```

## Measured results (uploaded README, CPU, 2026-11-05)
Sample corpus, 268,416 parameters, 300 steps, 4.7 s:
- train loss 0.678 · val loss 0.694 · test loss 0.690 · test perplexity 1.99

**Honest interpretation:** this corpus is tiny and highly repetitive, so low loss only shows the pipeline learns its pattern. The model reproduces sentence templates; it is **not intelligent** and has no general knowledge. Real capability needs a large licensed corpus and GPU training.

## Data provenance
- `data/sample_corpus.txt` — generated by a deterministic script (seed 0) from word lists written for this project. Original work, released CC0. Contains no third-party text.
- Recommended licensed corpora for the next phase (verify each license before use): TinyStories (CDLA-Sharing-1.0), WikiText-103 (CC BY-SA 3.0), Project Gutenberg public-domain books (check per-book, US public domain), The Stack v2 permissive-license subset for code. Record source URL, license, date and SHA-256 of each file you train on.
