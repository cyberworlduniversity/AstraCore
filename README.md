# AstraCore

AstraCore is an experimental, local-first AI platform focused on building an independently trainable neural language model and a modular AI runtime.

## AI v0.1

The first milestone establishes the project architecture for:

- a local `/api/chat` interface
- tokenizer and vocabulary components
- a small decoder-only language-model foundation
- inference and sampling
- training and checkpoint abstractions
- conversation context and memory boundaries
- safety and resource controls
- automated testing

AstraCore v0.1 is an engineering foundation, not a claim of GPT-class capability.

## Principles

1. No mandatory commercial AI provider for core inference.
2. Local-first architecture.
3. Small, testable modules before model scaling.
4. Honest benchmarks and capability reporting.
5. Security and privacy by default.

See `docs/ASTRACORE_AI_ARCHITECTURE.md` for the initial architecture.
